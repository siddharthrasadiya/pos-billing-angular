Set up Google Drive (once, by the app owner)

  1. Open console.cloud.google.com → create a project (e.g. "POS Billing").
  2. APIs & Services → Library → enable Google Drive API.
  3. OAuth consent screen → External → app name, your email → add scope …/auth/drive.file → Publish the app.
  4. Credentials → Create credentials → OAuth client ID → Web application → Authorized JavaScript origins: {{ origin }} and your GitHub Pages address.
  5. Copy the Client ID into GOOGLE_CLIENT_ID in app.constant.ts, then deploy.
